Odoo & Stream Transport Integration

The Rishvi Stream Connector provides a structured, reliable approach to export and synchronise transport data between Odoo and the Stream TMS - with full webhook support, automated schedulers, and real-time status tracking.

Sale Order Export to Stream

Export confirmed Odoo sale orders directly to Stream with a single click or via automated scheduler. Supports Collection, Delivery, and Multi order types with full payload customisation per order line.

Consignment & Tracking Management

Automatically capture Stream Consignment Numbers, Tracking IDs, and Tracking URLs back into Odoo on export. Give your team live visibility of every shipment from within the sales order.

Order Status Synchronisation

Keep Odoo sale orders in sync with Stream status updates - Unconfirmed, Confirmed, Planned, Released, Collected, Delivered, Completed, and Cancelled. Updates are reflected automatically via webhook or scheduled cron.

Run Details & Driver Tracking

Retrieve full run details from Stream including Run ID, vehicle, driver name, dispatch status, planned and actual datetimes, and GPS coordinates - all stored directly on the Odoo sale order.

Depot & Delivery Method Management

Fetch and manage Stream Depots directly in Odoo. Map Odoo delivery carriers to Stream Delivery Methods and configure shipping services per order. Full depot list with city, country, and contact information synced from Stream.

Full-Featured Stream Integration Capabilities

The Rishvi Stream Connector provides a complete set of export and sync features - covering every key transport entity in both Odoo and Stream, with flexible configuration options to match your logistics workflow.

Order Type Support: Export Collection, Delivery, and Multi order types to Stream - each with fully structured payloads including address, contact, items, and service codes
Webhook Integration: Register and retrieve Stream webhooks directly from Odoo. Receive real-time status updates from Stream and automatically update sale order status with chatter notifications
Stream Shipping Services: Configure and assign Stream service codes per order. Manage your full service list within Odoo and attach multiple services to individual sale orders
Automated Schedulers: Set up cron jobs to automatically export confirmed sale orders to Stream, sync order statuses, and retrieve run details on a configurable schedule
Per-Order Export Button: Export any individual sale order to Stream instantly using the "Export → Stream" button directly on the Odoo sale order form - no need to run a full batch job
Chatter Notifications: Every Stream status update is automatically logged in the Odoo sale order chatter - giving your team a full audit trail of transport events without leaving Odoo

Advanced Stream Integration Capabilities

Multi-Company Support

Run multiple Odoo companies each with their own Stream credentials. Company-specific Client ID, Client Secret, and Base URL configuration ensures orders are always routed to the correct Stream account.

Flexible Order Type Payloads

Choose between Collection, Delivery, and Multi order types per sale order. Each type generates a fully structured Stream payload with appropriate address blocks, delivery methods, booking flags, and item lines.

OAuth2 REST API

Secure, modern authentication using Stream's OAuth2 client credentials flow with nonce headers. Compatible with Odoo.sh, Enterprise, Community, and self-hosted environments.

Stream Integration on the Odoo Sale Order

The Rishvi Stream Connector extends the Odoo sale order form with a dedicated Stream tab - giving your operations team a complete view of every transport event without leaving Odoo.

Key Highlights:

Stream Tab: View Stream Consignment No, Tracking ID, Tracking URL, Stream Status, and full Run Details (vehicle, driver, datetimes, postcodes) directly on the sale order.
Real-Time Status Updates: Stream status changes (Planned, Collected, Delivered, etc.) are reflected on the order and logged as chatter messages automatically via webhook or cron.
Sync Run Details Button: Fetch the latest run details from Stream at any time using the "Sync Run Details" button on the confirmed sale order - no manual data entry required.
